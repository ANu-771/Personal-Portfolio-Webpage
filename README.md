# 🌐 Personal Portfolio Website

A modern and fully responsive **Personal Portfolio Website** developed using **HTML, CSS, and JavaScript** as part of the **ITS1119 - Web Technologies Assignment**.

This project showcases personal information, technical skills, projects, academic work, and professional goals while demonstrating strong frontend development and UI/UX design principles without using external frameworks.

## 📌 Project Overview

The main objective of this project is to design and develop a professional portfolio website that represents my identity, skills, achievements, and technical experience.

The website is designed with a modern UI/UX approach and optimized for multiple screen sizes including desktop, laptop, tablet, and mobile devices.

---

## 🎯 Assignment Objectives

- Develop a professional portfolio website
- Apply modern UI/UX principles
- Implement responsive web design
- Practice semantic HTML structure
- Improve CSS styling and layout techniques
- Enhance JavaScript interactivity
- Build a framework-free frontend application
